# 🚀 Projeto FinanZen (Enterprise MVP)

Este é o projeto principal de gestão financeira, evoluindo de uma ferramenta pessoal baseada em WhatsApp para um sistema corporativo Multi-Filiais.

## Status Atual
- [x] **Fase 1:** Modelagem de Dados Relacional e Base Arquitetural Multi-Filiais (Prisma).
- [x] **Fase 2:** Desenvolvimento do Módulo Multi-Filiais e Cadastros Base (Filiais, Clientes, Plano de Contas).
- [x] **Fase 3:** Módulo Operacional e Transacional (Frente de Caixa, Pagar/Receber).
- [ ] **Fase 4 & 5:** Inteligência Financeira, Fluxo de Caixa e DRE.
